# Scope: where your issue lives

## Where your issue lives

Only plan packages for issues in the configured repository are in scope:

- Repo: `<owner/repo>`

Replace the placeholder with the target repository before running
live mode. While it is still a placeholder, the skill stops without
grading. Eval mode never reads this file.

The plan must belong to the issue you reproduced.

## Rules of the room

- **Claims count.** An assignee, an open linked PR, or a recent
  "I'll take this" comment means someone else got there first. Read
  claim signals exactly as the rubric states them.
- **Claim upstream the moment you commit.** When you decide to take
  an issue, say so on the issue (what you plan to do, roughly when).
- **Follow the repository's own rules.** Its CONTRIBUTING guide, PR
  template, and any AI-use policy outrank anything in this toolkit.
- **Never piggyback a plan.** "Same approach as above" is not a plan
  comment: your diagnosis, scope, and test plan come from your own
  reproduction.
